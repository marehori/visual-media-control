# Changelog

## 1.0.0

- First public release as Visual Media Control
- Single-key artwork with dynamic Play / Pause state
- Synchronized 2x2 artwork grid with D6 bezel-gap compensation
- Play / Pause, Previous, Next, Title, and artwork-only grid modes
- Configurable icon, text, shadow, outline, backdrop, and gradient styles
- Per-key custom PNG icons
- FIFINE D6 installer, uninstaller, media diagnostic, and local tests
- Separate full and folder-only manual installation packages
